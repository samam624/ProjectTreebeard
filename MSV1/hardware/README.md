# MSV1 probe PCB

The first generation, an analog prototype. A printed-circuit electrode is read by 555 timers,
analog filtering and a comparator. The oscillation ran from about 27 kHz in dry potting soil to
7.5 kHz wet, and the electrode measured from 274 pF in dry air to about 1.28 nF saturated.
