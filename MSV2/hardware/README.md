# MSV2 probe PCB

Two-layer probe carrying a Seeed XIAO nRF52840 Sense module. Soil moisture sets the frequency of an
oscillator, which the module counts and broadcasts over Bluetooth LE. Power is a small battery,
charged from a solar panel through a BQ25100 USB charger.
